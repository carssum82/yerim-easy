# 로그인 화면에 ERP 예시 화면 팝업 추가 — 회사 PC의 Claude Code에 붙여 넣을 요청문

> 아래 "요청문" 부분을 회사 PC(호남배송업무 폴더)의 Claude Code에 그대로 붙여 넣으세요.
> 같은 폴더의 `erp_배차등록_예시.png`(이름·금액 가림)와 `erp_popup_snippet.html`(참고 코드)을 먼저 프로그램 폴더로 옮겨 두세요.

---

## 요청문

로그인 화면에 ERP 배차등록 예시 화면을 잠깐 보여 주는 기능을 넣어 주세요.

1. **이미지 파일**: `프로그램/화면/erp_배차등록_예시.png` 로 둡니다. (제가 미리 넣어 둔 파일, 거래처명·금액은 가린 버전)
2. **링크**: 로그인 화면(`로그인.py`) 로그인 버튼 아래에 **희미한 작은 글씨 링크** "ERP 배차등록 화면 보기"를 넣어 주세요. 연회색, 버튼 모양 아님, 눈에 띄지 않게.
3. **팝업**: 링크를 누르면 같은 화면 위에 팝업(어두운 반투명 배경 + 흰 창)으로 이미지를 크게 보여 줍니다.
   - 닫기 버튼, 바깥 클릭, ESC 키로 닫힘
   - 폰·태블릿에서도 화면 폭에 맞게 보이고, 크면 스크롤
   - 새 창(window.open)이 아니라 페이지 안 팝업
4. **외부 접속**: 로그인 전·외부 접속에서도 이 이미지가 열려야 합니다.
   - `baecha_server.py` 의 로그인 없이 허용하는 경로 목록을 확인하고, **이 이미지 파일 하나만** 허용해 주세요. (`화면` 폴더 전체나 다른 파일을 새로 열지 말 것)
   - 서버를 고쳤다면 재시작이 필요하다고 알려 주세요.
5. 참고 코드: `erp_popup_snippet.html` 의 "복사" 표시 부분(CSS·HTML·JS)을 로그인 화면 구조에 맞게 넣으면 됩니다.

작업 원칙(CLAUDE.md)대로: 수정 전 `프로그램/백업/로그인_ERP예시전/`에 백업, 먼저 수정 모습을 보여 주고 "적용" 후 반영, 끝나면 `문서/작업인계.md`에 한 줄 기록. 회사 PC·외부 접속에서 실제로 열리는지는 확인한 것과 못 한 것을 나눠서 알려 주세요.
